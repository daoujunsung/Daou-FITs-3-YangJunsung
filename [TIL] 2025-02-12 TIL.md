**MVC Pattern**
- Layered Architecture(4-tier)
  - Presentation Layer: 입출력 처리
  - Business (Logic) Layer: 로직 처리
  - Persistence Layer: 데이터베이스 처리
  - Database Layer: 실제 데이터베이스
  - 각 층은 인접한 층이랑만 데이터 통신 가능
- MVC(Model-View-Controller) Pattern
  - Model
    - Data Model: VO
    - Service Model(Business Layer)
      - 로직 처리를 하는 객체
      - DB 처리는 하지 않음
      - Transaction 담당
  - View
    - Presentation Layer에 해당
    - 입출력을 담당
  - Controller
    - View와 Service Model 사이에 위치하여 둘을 연결
    - View에서 입력된 값을 적절한 Model에 전달해주고 출력값을 View로 보내주는 역할
  - DAO(Data Access Object)
    - Persistence Layer에 해당
    - 서비스 모델이 직접 데이터베이스를 처리할 수 없기 때문에 데이터베이스 처리를 위한 객체
    - 비즈니스 로직 처리를 하지 않음
    - DB Access 처리만 허용

  KUserDAO.java
  ```
  public class KUserDAO extends UserDAO {
      // 추상 클래스를 상속을 해서 사용하는 측에서 이 메서드를 자신에게 맞게
      // Overriding 해서 사용
      @Override
      public Connection getConnection() {
          Connection conn = null;
          try {
              Class.forName("oracle.jdbc.driver.OracleDriver");
  
              String url = "jdbc:oracle:thin:@localhost:1521:xe";
              String id = "C##DEV";
              String pw = "4587";

              System.out.println(e.getMessage());
          }
  
          return conn;
      }
  }
  ```
  - 사용자는 상속해서 사용 가능 (KUserDAO가 UserDAO를 상속)
  - 재활용성의 측면에서 나아짐
  - Template Method Pattern
    - 상위 클래스에서 기본적인 로직의 흐름을 구현
    - 하위 클래스에서 구체적인 구현 내용을 변경해서 구현
  - 자바는 다중 상속이 불가능하기 때문에 이미 상속하고 있는 클래스에 붙여쓸 수 없는 문제가 있음

- Step6. 의존성 주입(DI, Dependency Injection)
  UserDAO.java
  ```
  public class UserDAO {
  
      private ConnectionMaker connectionMaker;
  
      public UserDAO(ConnectionMaker connectionMaker) {
          // 직접 객체를 생성하는 것이 아니라
          // 객체를 injection 받아서 사용(DI, Dependency Injection)
          // 생성자 주입: 생성자를 통해서 주입받음
          this.connectionMaker = connectionMaker;
      }
  
      // 새로운 사용자 등록
      public void insert(UserVO user) {
          // 데이터베이스 처리 6단계
          try {
              Connection conn = connectionMaker.makeNewConnection();
  
              String sql = "INSERT INTO users VALUES (?,?,?)";
              PreparedStatement pstmt = conn.prepareStatement(sql);
              pstmt.setString(1, user.getId());
              pstmt.setString(2, user.getName());
              pstmt.setString(3, user.getPassword());
  
              pstmt.executeUpdate();
  
              pstmt.close();
              conn.close();
          } catch (Exception e) {
              System.out.println(e.getMessage());
          }
      }
  
      // 이하 생략...
  }
  ```
